# Ruxsora Odilbekova — Portfolio

A responsive portfolio with an restrained ink and navy palette. It includes a light/dark switch, mobile navigation, custom skill icons, project cards, education, achievements, languages, and contact links.

## Add your photo to the hero
Place your portrait image at `images/profile.jpg`. The layout will automatically show it in the hero section. A placeholder appears until the photo is added. Use a clear portrait photo with the face visible and a vertical crop works best.

## Before publishing
Replace these sample details in `index.html`:
- `YOUR_EMAIL@example.com`
- `YOUR_TELEGRAM_USERNAME`
- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`

Add real links to your project repositories or live demos. Project visuals are illustrations and should be replaced with screenshots if available. Review all project descriptions and only keep claims and technologies that accurately describe your work.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension. Google Fonts require an internet connection; system fallbacks are included.


## Project buttons
Each project card has a "Visit project website" button. Replace these placeholder links in `index.html`:
- `https://YOUR_BEMOROVOZI_LINK`
- `https://YOUR_SCHOOL_VOTING_BOT_LINK`
- `https://YOUR_DRAND_EDU_LINK`
- `https://YOUR_EXAMLAB_LINK`

(Murojaat.uz already links to its live demo.) Project artwork is illustrative; swap in real screenshots when you have them.

Fonts: Newsreader + Hanken Grotesk (Google Fonts, with system fallbacks).
